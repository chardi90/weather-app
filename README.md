# Basic Weather App
A simple weather webapp which displays the current weather conditions with a city search function. Built using SheCodes layout design, weather API and JavaScript, then deployed on Netlify.

## Features  
- Search function - powered by weather api
- Current temperature, wind speed, humidity and weather description

## Installation  
Clone the repository and install the required packages:  

```bash  
git clone https://github.com/chardi90/weather-app.git  
cd weather-app
pip install -r requirements.txt 
``` 

## Usage  

You may want to research alternative weather apis. This project currently uses:
[SheCodes Weather API](https://www.shecodes.io/learn/apis/weather)

- API key required
